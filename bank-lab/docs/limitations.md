# 적용 범위와 한계

- 모든 계정·계좌·메일·문서는 가상 데이터입니다. 실제 은행이나 인터넷 서비스와 연결하지 않습니다.
- 공개 경계 방화벽은 HTTP 경로·메서드 허용 목록입니다. 패킷 필터, 전체 호스트 송신 차단, 침입 탐지 엔진은 아닙니다.
- 감사 저장소는 한 Docker 호스트의 SQLite 볼륨입니다. 독립 오프호스트 백업, 불변 저장소, 다중 지역 복구를 제공하지 않습니다.
- 중앙 감사 서비스가 응답하지 않으면 서비스는 stdout에 원본 이벤트와 전송 실패를 남깁니다. Docker stdout 회전 설정 때문에 장기 보존은 별도 수집 정책이 필요합니다.
- 중앙 기록의 `sha256`은 저장된 JSON의 무결성 대조용입니다. 외부 서명이나 변조 불가능성을 보증하지 않습니다.
- 컨테이너 내부에 eBPF 센서를 탑재하지 않습니다. Linux 커널 수준 로그가 필요한 프로젝트는 호스트 환경에서 별도 수집기를 연결해야 합니다.
- Docker 브리지는 물리적 회사 네트워크와 다릅니다. 실제 배포에서는 방화벽, TLS, 비밀관리, 백업, 모니터링, 권한 분리를 별도로 설계해야 합니다.
